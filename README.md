## Deploy
1. Create `<your-github-username>.github.io`.
2. Upload `index.html`, `style.css`, `script.js` to the repository root.
3. GitHub → Settings → Pages → Deploy from a branch → `main` / `/root`.

Keep credentials, private infrastructure, tokens, IPs and sensitive investigation information out of the public repository.
